# 🚚 Smart Logistics Services System (Tawzie Tech)

A comprehensive smart logistics and distribution management system developed to optimize supply chain operations, track distribution fleets in real-time using digital maps, and provide data-driven business intelligence reports[cite: 3, 4].

---

## 📌 About the Project
Traditional product distribution often suffers from inefficient manual routing, lack of real-time monitoring, high operational costs, and poor inventory control[cite: 3]. **Tawzie Tech** bridges this gap by offering an integrated solution consisting of:
1. **Web Dashboard (Admin Panel):** For administrators to manage products, monitor active distributors in real-time, view heat/cluster maps of sales, and analyze performance reports[cite: 3].
2. **Mobile Application (Distributor App):** Built with Flutter, enabling field agents to place product orders, add new points of sale, track routes, and record transactions within a precise geographical radius[cite: 3, 4].

---

## 🛠️ Tech Stack & Tools
* **Front-End & Mobile:** Flutter, Dart, Bootstrap 4, HTML5, CSS3, JavaScript[cite: 3]
* **Back-End:** Laravel 8 (PHP MVC Architecture)[cite: 3]
* **Database:** MySQL (Normalized relational database schema)[cite: 3]
* **Mapping & GIS:** Leaflet.js, Mapbox.js, Google Maps API, ArcGIS[cite: 3]

---

## ✨ Key Features
* **Real-Time Tracking & Monitoring:** Live tracking of distribution vehicles and agents on interactive digital maps[cite: 3, 4].
* **Geo-fencing Sales Enforcement:** Sales transactions via the mobile app are restricted to a 200-meter radius from the designated distribution point[cite: 3].
* **Smart Ordering System:** Distributors can request specific product quantities based on real-time inventory availability[cite: 3].
* **Advanced Data Visualization & Reporting:** Generates interactive charts, heat maps, and cluster maps to highlight high-demand regions and top-selling products[cite: 3].
* **Point of Sale (POS) Management:** Dynamic addition, updating, and removal of distribution points directly from the field[cite: 3].
